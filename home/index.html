MÓDULOS DEL SISTEMA

Servicios Principales

🏨

Servicio de Hoteles

Administra la información general de los alojamientos (nombre, ciudad, dirección) y expone endpoints REST completos.

Flask + MySQL
👤

Servicio de Clientes

Gestiona los usuarios y se comunica internamente con el servicio de hoteles mediante solicitudes HTTP REST síncronas.

Flask + Requests + MySQL
