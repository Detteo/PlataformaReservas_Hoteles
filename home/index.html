MÓDULOS DEL SISTEMA

Servicios Principales

👤

Servicio de Clientes

Permite el registro de usuarios en la plataforma para habilitar sus reservaciones.

Flask + Requests + MySQL
🏨

Servicio de Hoteles

Expone el catálogo de alojamientos disponibles administrados en el sistema (nombre, ciudad y dirección).

Flask + MySQL
📅

Servicio de Reservas

Gestiona las reservaciones validando cliente y hotel con timeouts y circuit breaker.

Flask + PyBreaker + MySQL
